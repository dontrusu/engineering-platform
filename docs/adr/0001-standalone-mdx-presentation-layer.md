# Standalone MDX presentation layer

**Status:** accepted
**Date:** 2026-08-22
**Project:** Platform

The platform is a standalone repository and presentation layer. Projects remain in separate repositories, while the platform authors Case Studies and Notes directly in MDX; MVP excludes a database, authentication, CMS, and admin surface. This keeps the implementation proportional to the small, authored content set and preserves the projects as the evidence-bearing systems.
