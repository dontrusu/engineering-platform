# Content-driven route availability

**Status:** superseded by ADR-0007
**Date:** 2026-08-22
**Project:** Platform

The Projects index may show all three Projects, but only Projects with approved internal Project Page content receive detail routes. Atlas has an interim Project Page; Pulse and Composite remain listed without detail routes until their pages have approved content. This keeps planned work visible without presenting it as completed Evidence. See ADR-0007 for the current route and status model.
